Security

Honest about what it protects.

No magic, no marketing. Here is exactly how your keys are kept.

What it does

  • Keeps keys in ~/.mcpcreds/store.json, readable only by your user (folder 0700, file 0600). Atomic writes.
  • The app only listens on 127.0.0.1 and opens with a one-time link plus a session cookie, so neither websites nor other accounts on your computer can read your keys.
  • Independently audited with Cloudflare's security-audit method. Read the report.
  • Takes tokens out of your AI app configs, so they stop leaking into backups, screenshots and dotfile repos.
  • Backs up every config before touching it, refuses configs with comments, and never overwrites the original backup.

What it does not

  • It does not encrypt the file. Protection is the same as ~/.aws/credentials or a .env file.
  • Any program running as you can read it, and any AI app you connect can ask for a key. Only connect apps you trust.
  • It is not a team password manager. It is one person's keys on one machine.
FAQ

Questions, answered.

What is MCP Creds?

A small desktop app that keeps all the API keys and tokens your AI apps need in one local file. You save a key once, connect MCP Creds to your AI apps once, and they fetch keys from it through the Model Context Protocol (MCP), the standard plug-in system for AI apps.

Does it work with ChatGPT, Gemini or local models?

Yes. MCP Creds talks to the app, not the model. Any model works inside any app that supports MCP: Claude Desktop, Claude Code, Cursor, Windsurf, VS Code and others. Apps without MCP support cannot use it.

Do I have to tell the AI which key to use?

No. MCP Creds tells the AI to check it whenever a task needs a key. Just ask for the task. For other MCP servers, the token is handed over at startup, so the AI does not need to do anything.

How do I give an MCP server its token without pasting it into the config?

Start the server through MCP Creds: python3 mcpcreds.py run -e GITHUB_TOKEN -- npx your-server. It sets the saved key as an environment variable and starts the server. In the app, "Move them into MCP Creds" rewrites your existing configs this way for you.

How do I store AWS credentials with an access key and a secret?

Paste them together into one key, one per line, or let MCP Creds split them into separate keys. The AI is told to read every part, and run -e AWS_SECRET_ACCESS_KEY=AWS_CREDENTIALS hands just the right part to a server.

Is my data sent anywhere?

No. There is no cloud, account or telemetry. Keys stay in ~/.mcpcreds/store.json on your machine. The code is open source, so you can check.

macOS says the app is from an unidentified developer.

The app is not notarized by Apple yet. Right-click it in Applications and choose Open the first time. After that it opens normally. Prefer not to? Run it from source with python3 mcpcreds.py ui.

Is it free?

Yes. Free and open source under the MIT license. Issues and pull requests are welcome on GitHub.
